# Synthetische e-mailpreviews

Deze bestanden bewijzen de Nederlandse HTML- en tekstinhoud van de duurzame
orderbevestiging zonder een provider aan te roepen. Alle namen, adressen,
ordernummers, bedragen en contactgegevens zijn expliciet synthetisch.

De production rendering staat in `server/email/render.ts`. Brevo-template-ID's
blijven environment-specifieke secrets/configuratie en horen niet in deze map.
