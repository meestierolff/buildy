# Feedback operations

## Doel

Feedback is een kernfeature van de feedbackbèta.

## Categorieën

- Iets werkte niet
- Iets was onduidelijk
- Idee of wens
- Ontwerp en gebruik
- Bouwboek
- Anders

## Altijd opslaan

- user ID wanneer beschikbaar
- huidige route
- categorie
- optionele rating
- vrije tekst
- app-versie
- timestamp

## Niet naar analytics

- vrije tekst
- e-mail
- naam
- foto- of Blob-URL

## Operatorwerk

- controleer nieuwe feedback regelmatig
- exporteer feedback alleen via veilige query of CSV-export
- publiceer feedback nooit
