The route inventory is taken from [`src/App.tsx`](../src/App.tsx), navigation from [`src/components/Header.tsx`](../src/components/Header.tsx), [`src/components/app/MobileNav.tsx`](../src/components/app/MobileNav.tsx), and [`src/components/Footer.tsx`](../src/components/Footer.tsx), and the API inventory from [`server/http/router.ts`](../server/http/router.ts).

## Status contract

Every status cell below contains exactly one of these values:

- `automated+passing`: the cited, directly related automated regression passed in the recorded Vitest, Playwright or clean-room database snapshot. It does **not** claim an interactive browser, Preview, provider, or production verification.
- `interactively verified+regression`: both the required in-app-browser action and a related regression passed. There are no rows with this status in this snapshot.
- `intentionally removed`: the action is deliberately absent from the active MVP; append-only database history may still describe the retired shape.
- `BLOCKED`: evidence is absent, failed, skipped, provider-dependent, or otherwise insufficient for a truthful green claim.

Therefore interactive verification for every route remains `BLOCKED`. See
