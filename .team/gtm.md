# GTM Audit

## Launch Sequence

1. Private alpha with 5-10 real renovation projects.
2. Validate upload, update, sharing and photobook ordering.
3. Ship paid Bouwboek checkout in test mode end-to-end.
4. Order one real proof copy.
5. Public beta with a clear "Bouwboek maken" offer.
6. Expand acquisition through renovation communities and contractor partnerships.

## Activation Metric

User creates a project and posts 3 updates with at least 8 photos.

## Revenue Metric

Photobook checkout conversion from projects with 10+ updates.

## Retention Loop

Followers and comments pull users back during the renovation. The Bouwboek creates the end-of-project monetization moment.

## Must-Have Before Public Paid Launch

- Working Stripe live mode.
- Peecho production fulfillment tested with one paid proof order.
- Support inbox and refund policy.
- Basic analytics for signup, project created, update posted, photobook opened, checkout started, paid.
